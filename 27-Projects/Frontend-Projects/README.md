# 100+ Frontend Project Challenges

A progressive project ladder for learning frontend development by building instead of watching tutorials.

**Goal:** Build every project, publish the best ones, write a short README/blog for each, and refactor selected projects after learning new concepts.

## Rules

For every project:
1. Write requirements before coding.
2. Sketch the UI before coding.
3. Build the HTML structure.
4. Build responsive CSS.
5. Add JavaScript behavior.
6. Handle loading, empty, error, and success states where relevant.
7. Test keyboard navigation and mobile layouts.
8. Refactor after the first working version.
9. Add a README explaining decisions and lessons learned.
10. Never copy a tutorial project line-for-line.

## Completion Standard

Do not measure progress by the number of projects completed alone. For every major project, you should be able to:

- explain the requirements;
- draw the UI and data flow;
- break the project into components/modules;
- explain your state model;
- handle loading, error, empty, and success states;
- debug a broken feature without a tutorial;
- explain important code decisions;
- write tests for important logic;
- make the UI responsive and keyboard usable;
- identify performance bottlenecks;
- refactor the first version;
- deploy the project;
- write a project README/blog;
- teach another beginner how it works.

**Recommended target:** complete 30 small projects, 10 medium projects, and 5 advanced projects deeply rather than rushing through all 120.
