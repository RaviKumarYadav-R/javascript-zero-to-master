# JavaScript Zero to Master

A teacher-ready JavaScript curriculum from absolute beginner to advanced/mastery.

## Learning Philosophy

`Learn → Understand → Visualize → Execute → Predict → Practice → Debug → Build → Teach → Master`

This repository is designed to make you capable of solving unfamiliar JavaScript problems and explaining the language clearly to another learner.

## Depth Standard

Every major topic is treated as a full chapter rather than a cheat sheet. Each chapter should cover definition, motivation, mental model, terminology, syntax, examples, execution flow, internal behavior, rules, edge cases, wrong/correct examples, debugging, performance, security where relevant, related concepts, practice, interview questions, teach-back questions, a mini challenge, and a mastery checklist.

**Minimum standard: 100 meaningful educational lines per major topic.** This is a depth floor, not a filler target.

## Practice Ladder

L1 Recall → L2 Understand → L3 Predict → L4 Apply → L5 Debug → L6 Design → L7 Teach → L8 Build → L9 Review → L10 Master

## Quality Rules

- Prefer runnable examples over passive reading.
- Explain why a rule exists, not only what the rule says.
- Use precise JavaScript terminology.
- Show expected behavior and common incorrect behavior.
- Use accurate mental models; do not describe primitives as if every value were a memory address.
- Prefer modern JavaScript while explaining important legacy behavior.
- End every major chapter with practice and teach-back material.

## Goal

Complete this repository able to read unfamiliar JavaScript, predict execution, debug systematically, design reusable code, build projects without tutorials, and teach JavaScript from first principles.
